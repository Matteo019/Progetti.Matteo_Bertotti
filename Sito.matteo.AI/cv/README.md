# CV

`build_cv.py` genera i due CV (inglese e italiano) in `frontend/public/images/`:
il sito scarica quello nella lingua della pagina.

```bash
pip install reportlab
python cv/build_cv.py
```

I testi sono nel dizionario `CV` dentro lo script. Font: CMU Serif (Computer Modern Unicode, SIL OFL) in `cv/fonts/`.
